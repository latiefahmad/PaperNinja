## What's new in 1.0.2-beta.1

A beta release to exercise the release pipeline. It is signed like a real
release and it is the first version that can update itself — which is exactly
why it exists.

- **PaperNinja can now update itself.** When a newer release is published on
  GitHub, the app downloads it in the background while you keep working, shows
  the progress, and then asks whether to restart now or later. "Later" is
  remembered for that version, and the check runs again every six hours. If
  the update feed is unreachable, the app links the release page as before.
- **Support links now go to Saweria** ([saweria.co/latiefahmad](https://saweria.co/latiefahmad))
  instead of Buy me a coffee, across the app, the landing page and this
  repository.
